  <action>
    Document success criteria and phased migration approach:

    **Target Metrics:**
    - Hardcoded spacing: 40-50% → <10%
    - SizedBox(height: N) instances: Current count → <20 total
    - EdgeInsetsDirectional.fromSTEB: Current count → <10 total (unavoidable cases only)
    - Off-grid values: Current count → 0
    - AppSpacing token usage: 50-60% → 90%+

    **Migration Strategy:**
    - Wave 2 parallel execution (04-02 game/social, 04-03 profile/auth)
    - Screen-by-screen approach (same as typography migrations)
    - Priority: Fix off-grid values first, then replace common patterns
    - Visual verification: Ensure spacing changes don't break layouts

    **Anti-Patterns to Avoid:**
    - Don't batch-replace without verification (layouts may depend on exact pixel values)
    - Don't introduce new hardcoded values during migration
    - Don't skip off-grid value normalization (breaks visual grid)

    Include file-by-file checklist for Plans 04-02 and 04-03.
