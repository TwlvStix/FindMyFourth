  <name>Task 1: Audit design token adoption metrics</name>
  <files>lib/</files>
  <action>
    Verify final design token adoption rates across the codebase and compare to baseline from Phase 1.

    **AppSpacing adoption:**
    1. Count AppSpacing usages: `grep -r "AppSpacing\." lib --include="*.dart" | wc -l`
    2. Count hardcoded SizedBox heights: `grep -r "SizedBox(height:" lib --include="*.dart" | wc -l`
    3. Count EdgeInsetsDirectional.fromSTEB: `grep -r "EdgeInsetsDirectional.fromSTEB" lib --include="*.dart" | wc -l`
    4. Count off-grid values (2px, 6px, 10px, 15px): `grep -r "EdgeInsets.*: [26]\.0\|EdgeInsets.*: 1[05]\.0" lib --include="*.dart" | wc -l`
    5. Calculate adoption rate: AppSpacing / (AppSpacing + anti-patterns)

    **AppTypography adoption:**
    1. Count AppTypography usages: `grep -r "AppTypography\." lib --include="*.dart" | wc -l`
    2. Count AppText usages: `grep -r "AppText\." lib --include="*.dart" | wc -l`
    3. Count GoogleFonts.outfit usages: `grep -r "GoogleFonts\.outfit" lib --include="*.dart" | wc -l`
    4. Count AppTheme.override usages: `grep -r "AppTheme\.of.*\.override" lib --include="*.dart" | wc -l`
    5. Calculate adoption rate: (AppTypography + AppText) / (AppTypography + AppText + GoogleFonts + override)

    **AppColors adoption:**
    1. Count AppColors/AppTheme color usages: `grep -r "AppColors\.\|AppTheme\.of.*primary\|AppTheme\.of.*secondary" lib --include="*.dart" | wc -l`
    2. Count hardcoded hex colors: `grep -r "Color(0x[0-9A-F]\{8\})\|#[0-9A-Fa-f]\{6\}" lib --include="*.dart" | wc -l`

    **Component adoption:**
    1. Count AppButton/AppButtonEnhanced: `grep -r "AppButton\(" lib --include="*.dart" | wc -l`
    2. Count AppCard: `grep -r "AppCard\." lib --include="*.dart" | wc -l`
    3. Count AppTextField: `grep -r "AppTextField\(" lib --include="*.dart" | wc -l`
    4. Count total Container widgets: `grep -r "Container(" lib --include="*.dart" | wc -l`

    Compare all metrics to Phase 1 baseline (from 01-01-SUMMARY.md) and document improvements.
