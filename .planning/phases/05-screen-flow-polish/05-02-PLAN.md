## Migration Strategy (from Plan 05-01)

**TransitionStandards Available:**
- `TransitionStandards.modalTransition` - Modal-like screens (create, edit) - bottomToTop 220ms
- `TransitionStandards.detailTransition` - Detail views (game/chat details) - bottomToTop 220ms
- `TransitionStandards.dismissalTransition` - Success screens - topToBottom 220ms
- `TransitionStandards.tabTransition` - Tab navigation - fade 200ms
- `TransitionStandards.noTransition` - No transition (instant)

**Patterns to Apply:**

1. **Game Detail Navigation** (games_list → game_details):
   ```dart
   // BEFORE
   context.pushNamed(GameJoinedDetailedWidget.routeName, ...)

   // AFTER
   context.pushNamed(
     GameJoinedDetailedWidget.routeName,
     extra: {
       ...params,
       kTransitionInfoKey: TransitionStandards.detailTransition,
     },
   )
   ```

2. **Modal Screens** (create_game, player_list):
   ```dart
   extra: {
     ...params,
     kTransitionInfoKey: TransitionStandards.modalTransition,
   }
   ```

3. **Post-Action Navigation** (after join game):
   ```dart
   // Already uses bottomToTop - verify duration is 220ms
   kTransitionInfoKey: TransitionInfo(
     hasTransition: true,
     transitionType: PageTransitionType.bottomToTop,
     duration: Duration(milliseconds: 220),
   )
   // Or use: TransitionStandards.detailTransition
   ```

4. **Fix Router.go()** (player_list):
   ```dart
   // BEFORE
   router.go(GamesListWidget.routePath)

   // AFTER
   context.goNamed(GamesListWidget.routeName)
   ```
