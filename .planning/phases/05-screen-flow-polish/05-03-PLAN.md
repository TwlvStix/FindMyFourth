## Migration Strategy (from Plan 05-01)

**TransitionStandards Available:**
- `TransitionStandards.modalTransition` - Modal-like screens (edit profile) - bottomToTop 220ms
- `TransitionStandards.detailTransition` - Detail views (chat details, profile views) - bottomToTop 220ms
- `TransitionStandards.dismissalTransition` - Success screens - topToBottom 220ms
- `TransitionStandards.tabTransition` - Tab navigation - fade 200ms
- `TransitionStandards.noTransition` - No transition (instant)

**Key Patterns to Apply:**

1. **Chat Detail Navigation** (chat/golfers → chat_details):
   ```dart
   extra: {
     ...params,
     kTransitionInfoKey: TransitionStandards.detailTransition,
   }
   ```

2. **Profile View Navigation** (golfers/game_details → profile_user):
   ```dart
   extra: {
     ...params,
     kTransitionInfoKey: TransitionStandards.detailTransition,
   }
   ```

3. **Fix Edit Profile Return** (edit_profile → main_profile):
   ```dart
   // BEFORE (wrong - pushes another screen)
   context.pushNamed(MainProfileWidget.routeName)

   // AFTER (correct - replaces stack after edit)
   context.goNamed(MainProfileWidget.routeName, extra: {
     kTransitionInfoKey: TransitionStandards.modalTransition,
   })
   ```

Fix the incorrect return navigation pattern in edit profile:

**Issue**: Edit profile currently uses `pushNamed` to return to main_profile after save (around line ~300+). This is wrong because:
1. It pushes another screen onto the stack instead of replacing
2. User can then "back" to edit profile again (confusing)
3. Duration is 300ms (non-standard)

**Fix 1 - Save Button Navigation:**
Find the save button's navigation to MainProfileWidget:
```dart
// BEFORE
context.pushNamed(
  MainProfileWidget.routeName,
  extra: {
    kTransitionInfoKey: TransitionInfo(
      hasTransition: true,
      transitionType: PageTransitionType.bottomToTop,
      duration: Duration(milliseconds: 300),
    ),
  },
);

// AFTER
context.goNamed(
  MainProfileWidget.routeName,
  extra: {
    kTransitionInfoKey: TransitionStandards.modalTransition,
  },
);
```

**Fix 2 - Delete Account Navigation:**
Find goNamed to SignInWidget (after account deletion):
```dart
// BEFORE
context.goNamed('SignIn');

// AFTER
context.goNamed(
  'SignIn',
  extra: {
    kTransitionInfoKey: TransitionStandards.modalTransition,
  },
);
```

**Why goNamed not pushNamed?**
- After saving edits, you're done with edit screen
- goNamed replaces stack, preventing back to edit screen
- Consistent with modal dismissal pattern

**Why modalTransition?**
- Edit profile is a modal-like screen (slides up from bottom)
- Return should feel like dismissing modal
- 220ms standard duration (not 300ms)

**Alternative**: Could use `Navigator.pop(context)` but goNamed is clearer and provides transition control.
