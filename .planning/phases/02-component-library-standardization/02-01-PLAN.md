```markdown
## Component Migration Guides

### AppButton → AppButtonEnhanced

**Status:** AppButton deprecated in Phase 2, will be removed in Phase 3

**Why migrate:**
- AppButtonEnhanced uses design tokens (AppBorderRadius, AppElevation)
- Better variant system for different button styles
- Consistent sizing with accessibility standards
- Built-in loading states

**Migration mapping:**
- AppButton with default style → AppButtonEnhanced(variant: AppButtonVariant.primary)
- AppButton with outlined → AppButtonEnhanced(variant: AppButtonVariant.secondary)
- AppButton with text-only → AppButtonEnhanced(variant: AppButtonVariant.ghost)

**Example:**
```dart
// OLD (deprecated)
AppButton(
  text: 'Join Game',
  onPressed: () => joinGame(),
)

// NEW (preferred)
AppButtonEnhanced(
  text: 'Join Game',
  variant: AppButtonVariant.primary,
  size: AppButtonSize.medium,
  onPressed: () => joinGame(),
)
```

Explain that existing AppButton usage will continue to work but will show IDE warnings.
